One room for two places.

A browser extension that keeps two people on the same frame of the same film, wherever they are. Play, pause and seek with the site's own player; everybody follows.

What it does

Stays locked

Small drift is closed by playing a fraction faster or slower, which nobody notices. Only a real gap gets a jump. Most watch-party tools scrub every time your network hiccups.

Says so

The panel reports whether you are actually together. When it slips you can see it slip, instead of wondering whether the app broke or your wifi did.

Chat in timecode

Messages are stamped with where you are in the film, not what time it is where you are, so the log reads back like notes.

Host can steer

Turn on host-only control and playback stops being a fight. It is enforced by the room itself, not by hiding a button.

No accounts

There is no sign-up, no sign-in, and no profile. You pick a name if you feel like it.

The link is the whole thing

Starting a room gives you one link. Whoever opens it lands on what you are watching and joins the room. The same link works again next weekend.

The room code and the destination ride in the link's fragment, the part after the #, which browsers never send to a server. So the relay learns neither which room you are joining nor what you are about to watch. That is a property of how the link is built, not a promise in a policy.

Nothing is stored about you anywhere. A room lives in memory while somebody is in it and is gone when the last person leaves.

Everyone brings their own account

Netflix and Crunchyroll are DRM-protected, so no extension can read or relay the video itself, and any that claimed to would be lying. Everyone plays the film on their own subscription; only the position crosses the wire. YouTube asks nobody for a subscription, but it works the same way here. That is also why it costs nothing to run.

Netflix Crunchyroll YouTube Any site you allow Hotstar, Prime Video, Disney+ later

Support for a service is one small file, so the list grows by request. Anything else with an ordinary video player works once you grant Abode access to that site, which it asks for at the moment you need it rather than at install.

Install

Abode is not on the Chrome Web Store yet. Until it is, it loads as an unpacked extension, which takes about a minute.

  1. Download the latest build from Releases and unzip it, or build it yourself with pnpm build:ext.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
  4. Open something to watch, click the Abode icon, then Start watching together. Send the link.

Which browser

Chrome. That is what Abode is built and tested on, and the only browser it is honest to promise. Chat lives in Chrome's side panel, so the video keeps its full width.

Other Chromium browsers may work. Nothing in Abode is Chrome-specific, and where a browser has no side panel the same chat is placed inside the page instead. That path is built and tested, but browsers that fork or skin Chromium differ in ways testing here cannot catch, so treat it as a maybe rather than a promise. If Abode misbehaves somewhere else, Chrome is the answer.

Run your own

The room server is a single Cloudflare Worker with a Durable Object. It fits inside the free plan, and the whole thing is two commands. 

pnpm install
pnpm --filter @abode/relay exec wrangler deploy

Then point the extension at it in the popup's server setting. There is no database, because there is nothing to store.
